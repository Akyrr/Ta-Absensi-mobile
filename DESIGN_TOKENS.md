# HADIRA Mobile - Design Tokens & Color Palette

Dokumentasi palet warna resmi aplikasi HADIRA Mobile (Sistem Presensi & Jurnal SMK).

## 1. Brand Colors
- **Brand Dark (Utama)**: `#282333` - Digunakan untuk tombol utama, ikon header buku, title utama, dan elemen fokus.
- **Brand Medium**: `#514857` - Digunakan untuk teks sekunder, subtitle, dan border tebal/aktif.
- **Brand Light**: `#807583` - Digunakan untuk teks pembantu (helper text), catatan keamanan, dan teks muted.

## 2. Background
- **Scaffold Background**: `#F5EFEF` - Latar belakang utama seluruh halaman.
- **Card / Surface**: `#FFFFFF` - Latar belakang kartu kontainer utama, kartu tombol kembali, dan dropdown.
- **Soft Background / Input Fill**: `#F9F5F5` - Latar belakang kapsul pill stepper dan input saat disabled/terkunci.

## 3. Typography & Teks
- **Teks Utama (Primary)**: `#282333` - Judul besar, label input, teks tombol kembali.
- **Teks Sekunder (Secondary)**: `#514857` - Subtitle dan deskripsi singkat.
- **Teks Muted (Pembantu)**: `#807583` - Informasi spam/email aktif dan pesan keamanan.
- **Teks Disabled / Hint**: `#C4BDC5` - Placeholder text input dan tombol nonaktif (rate limit).
- **Teks Putih**: `#FFFFFF` - Teks di atas tombol aktif dan ikon kontainer gelap.

## 4. Garis & Borders
- **Border Light**: `#D1C7D1` - Garis pembatas kartu tombol kembali dan kapsul stepper.
- **Border Medium**: `#B1A8B2` - Garis batas input normal (enabled border).
- **Border Dark**: `#514857` - Garis batas input saat focused.

## 5. Status Kehadiran & Notifikasi (H/I/A/S)
- **Hadir / Success**: `#4F7A64` - Indikator sukses, ceklis hijau, status hadir.
- **Izin / Warning / Rate Limit**: `#A47745` - Pesan peringatan batas waktu, status izin.
- **Alpa / Danger / Error**: `#A05252` - Pesan eror validasi, garis merah eror, status alpa.
- **Sakit / Info**: `#5C718A` - Indikator informasi umum, status sakit.

## 6. Latar Status (Banners & Chips)
- **Latar Hadir / Success**: `#EFF0EB` - Background badge sukses atau dialog konfirmasi.
- **Latar Izin / Warning**: `#F4EDE3` - Background banner rate limit countdown `01:00`.
- **Latar Alpa / Danger**: `#F4E7E7` - Background alert eror validasi.
- **Latar Sakit / Info**: `#E9EEF2` - Background info chip.
